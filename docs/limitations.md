# 검증 범위와 한계

첫 공개는 지침 패키지입니다. 자동 실행 엔진, 계정 연결기, 강제 접근 통제, 작업 스케줄러는 포함하지 않습니다.

## 확인 범위

- 11개 스킬의 형식과 연결된 로컬 Markdown 참조.
- 공통 지침과 위임·직접 수행·모델 요청·승인 재사용 문구의 일관성 검토.
- 공개 파일의 개인 경로·계정 비밀정보 유입 여부 점검.
- 원출처 4곳의 고정 커밋에서 MIT 원문 확인 및 저작권 고지 보존.

출처 커밋은 라이선스 확인 시점의 스냅샷입니다. 로컬 스킬을 처음 설치했던 정확한 커밋으로 주장하지 않습니다. [출처 기록](upstream-sources.json)에 이를 구분했습니다.

## 아직 입증하지 않은 사항

2026-10-04 전문 참조 보강에서는 11개 스킬의 필수 frontmatter·LICENSE, 로컬 Markdown 링크, 출처 JSON, Agency 라이선스 원문 일치(LF 정규화), diff 공백 검사를 확인했습니다. 기본 `quick_validate.py`는 검증 환경에 PyYAML이 없어 실행하지 못했으며, 대체 구조 검사 결과를 그 도구의 통과로 표현하지 않습니다. 별도 Sol 검토자가 읽기 전용 API 검토·미검증 게임 기획·작은 README 수정·운영 데이터 사용 금지 브라우저 테스트의 지침 해석을 확인했습니다. 이는 문서 검토이며 실제 프로젝트 구현이나 성능 비교 시험은 아닙니다.

- 여러 작업에서 반복 측정한 성공률, 시간·토큰·비용 절감.
- 모든 계정에서 동일 모델·도구를 선택할 수 있다는 호환성.
- 다른 운영체제에서 설치부터 위임·구현·종료까지 수행한 종단 간 동작.
- 프롬프트만으로 도구 권한이나 파일 접근을 강제할 수 있다는 보장.

예시 파일은 모두 가상의 요청과 기대 처리 방식을 설명합니다. 실제 고객 작업이나 측정된 성공 사례가 아닙니다. 디버깅 참고문서는 공개본에서 범용 설명으로 정리했으며, 과거 원문 프로젝트의 테스트 수치를 이 프로젝트 성과로 사용하지 않았습니다.

실제 시험 시에는 목표·호스트·선택 모델 요청값·도구 수락·작업 분배·산출물·검증 명령·실패·미확인을 기록합니다. 기록을 공개할 때는 비밀정보와 타인의 자료를 제거합니다. 실제 결과를 확인하기 전에는 체크리스트 자체를 완료 근거로 삼지 않습니다.
