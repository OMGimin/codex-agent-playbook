# 설치와 적용

## 프로젝트 단위로 시작하기

먼저 저장소를 내려받고 문서를 읽습니다.

```sh
git clone https://github.com/OMGimin/codex-agent-playbook.git
```

아래 `your-project`는 자신의 프로젝트 경로로 바꿉니다. 이것은 배치 결과 예시이며 자동 설치 명령이 아닙니다.

```text
your-project/
  AGENTS.md
  .agents/
    skills/
      work-orchestrator/
        SKILL.md
        LICENSE
        references/
      ... 나머지 스킬 폴더
```

1. 현재 프로젝트 지침·설치된 스킬·모델 지원을 확인합니다.
2. 기존 AGENTS.md와 같은 이름의 스킬을 백업한 뒤 차이를 검토합니다. 기존 스킬이 있으면 중복 설치 대신 어떤 버전을 사용할지 결정합니다.
3. 이 저장소의 `skills/` 아래 11개 폴더를 프로젝트의 `.agents/skills/` 아래에 복사합니다. 스킬 간 상대 참조를 위해 폴더 이름·구조를 유지하고 각 LICENSE도 함께 복사합니다.
4. `templates/AGENTS.md`를 기존 프로젝트 지침과 통합합니다. `멀티에이전트 운영 및 모델 정책`을 포함해 승인·안전 조건을 먼저 검토합니다. 스킬은 항목 번호 대신 정책 섹션명을 참조하므로 해당 섹션의 의미와 연결을 유지합니다. 기존 파일을 무조건 덮어쓰지 않습니다.
5. Codex에서 스킬 목록에 `work-orchestrator`가 보이는지 확인합니다. `$work-orchestrator`로 명시 호출하여 작은 읽기 작업부터 적용해 봅니다.

공식 문서는 프로젝트의 `.agents/skills` 경로와 스킬의 `name`, `description` 메타데이터를 설명합니다. 같은 이름의 스킬은 자동 병합되지 않습니다. 설치 방식은 사용하는 제품 버전의 [공식 스킬 문서](https://learn.chatgpt.com/docs/build-skills)를 함께 확인하세요. 확인일: 2026-09-25.

## 개인 전역 적용과 업데이트

이 구성의 원본 환경에서는 개인 스킬 경로를 사용했지만, 첫 적용에는 프로젝트 범위를 권장합니다. 전역 배치는 자신의 호스트가 실제로 읽는 경로를 확인한 후 진행합니다. 플러그인 캐시나 시스템 스킬 폴더를 덮어쓰지 않습니다.

업데이트할 때는 새 버전과 자신이 수정한 파일을 비교·통합합니다. 되돌릴 때는 이번에 추가한 폴더와 통합한 지침만 복원합니다. 다른 프로젝트의 스킬이나 기록은 삭제하지 않습니다.

## 기능·권한 확인

서브에이전트 생성, 모델 지정, 추론 강도, 동시 실행 수는 호스트가 제공하는 기능입니다. 지원되지 않으면 총괄이 직접 가능한 일을 진행합니다. 이 저장소는 자동 모델 전환, 계정 로그인, MCP 설치, 다른 작업 생성 또는 반복 실행을 수행하지 않습니다.

Git 절차의 Bash 예시는 설명용입니다. Windows에서는 PowerShell 등 현재 셸에 맞게 명령을 검토해서 사용합니다. 지침의 삭제 확인·작업트리 동의·브랜치 보호를 설치 과정에서 없애지 않습니다.
