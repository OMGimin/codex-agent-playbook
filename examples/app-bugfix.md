# 앱 오류 조사 요청 예시

이 문서는 가상의 사용 예시이며 실행 결과가 아닙니다.

```text
로그인 후 앱을 백그라운드에 두었다가 복귀하면 화면이 멈춰.
$systematic-debugging 을 사용해서 이번에는 네가 직접 조사해줘.
재현과 원인 판단, 수정안 제안까지만 해줘.
```

직접 수행 요청을 우선하므로 서브에이전트를 만들지 않습니다. 소스 분석, 재현 조건, 생명주기·세션 상태를 조사하되 구현으로 범위를 넓히지 않습니다. 기기나 로그인 환경이 없어 재현하지 못했다면 가설과 확인된 사실을 구분합니다.

기대 산출물은 재현 여부, 근거 위치, 원인 후보, 제안한 수정 범위, 후속 검증 방법입니다. 빌드 성공과 실제 기기에서의 정상 동작을 구분합니다.
